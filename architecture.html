👨‍🍳 주방 = FastAPI 서버main.py. 주문을 받아 창고에서 재료를 꺼내 줘요.
📦 창고 = Supabase제주 관광지 데이터가 저장된 곳이에요.

💡 헷갈리기 쉬운 점: 지금 내 컴퓨터에서는 Railway를 쓰지 않아요. 127.0.0.1:8000(내 컴퓨터, 8000번 문)에서 main.py가 직접 돌아가요. Railway는 나중에 이 주방을 인터넷 위로 옮겨 24시간 켜 두는 건물일 뿐이고, 프런트는 Vercel이 그 역할을 해요. 위 버튼으로 로컬/배포 모습을 비교해 보세요.

③ 폴더 안 파일은 각각 뭘 할까?

frontend/index.html홀

제주 관광지 화면. 열리면 주방(API)에 "관광지 목록 주세요" 하고 물어봐요. 실패하면 내장 데이터를 대신 보여줘요.

my-api/main.py주방

주문 접수처. /health(영업 중?), /spots(목록), /spots/번호(하나만)를 처리해요.

my-api/.env비밀

창고 열쇠(Supabase 주소·키)를 적어 둔 메모. 절대 남에게 보여주거나 git에 올리면 안 돼요.

supabase/schema.sql창고

창고에 "관광지 선반"을 만들고 12개 데이터를 채우는 설계도예요. Supabase에서 한 번만 실행해요.

my-api/requirements.txt

주방에 필요한 도구 목록(fastapi 등). Railway가 이걸 보고 알아서 설치해요.

my-api/Procfile

"주방 문 여는 방법" 한 줄. Railway가 이 명령으로 서버를 켜요.

🔑 왜 .env가 중요한가요? Supabase의 secret 키는 창고 마스터키예요. 그래서 키는 주방(서버)만 갖고, 손님 화면(index.html)에는 절대 넣지 않아요. 손님은 항상 주방을 통해서만 창고를 이용해요.

④ 용어 한 줄 정리

API = 주방의 주문 창구 · 포트(8000) = 건물 안의 문 번호 · 127.0.0.1 = "내 컴퓨터" 주소 · CORS = 주방이 "이 가게(주소) 손님만 받겠다"고 정한 출입 명단 · JSON = 주방이 손님에게 건네는 데이터 쪽지
